# PDF-Tools

A simple, modern PDF split and merge tool that runs locally in your browser.

## How to use

1. Open `index.html` in a modern browser.
2. Choose **Merge PDFs** to combine multiple files, or **Split PDFs** to create new files.
3. Drag and drop PDFs, reorder them, and download the results.

## Privacy

All processing happens locally in your browser. Your files are never uploaded or sent
anywhere.

## Features

- Drag & drop PDF uploads
- Reorder files before merging
- Split by custom ranges, every N pages, or into single-page PDFs
- Multiple split outputs in one click

> Note: The app loads `pdf-lib` from a public CDN to enable PDF editing. No PDF data
> leaves your device.
